# Will Box Backend

NestJS API service for Will Box. The service bootstrap is in place; application endpoints and storage/auth integrations have not been implemented yet.

## Run locally

```bash
npm install
npm run start:dev
```

The API listens on port `3001` by default. Set `PORT` to override it.

## Useful commands

- `npm run build` builds the service.
- `npm run lint` checks source and test files.
- `npm test` and `npm run test:e2e` run the Vitest unit and end-to-end suites. Test files will be added alongside the first API features.
