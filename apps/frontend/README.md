# Will Box Frontend

The Will Box web application, built with Next.js App Router, React, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

The development server runs at [http://localhost:3000](http://localhost:3000).

## Routes

- Public pages: `/`, `/get-app`, `/help-center`, and `/blog`
- Account pages: `/login` and `/register`
- Dashboard pages: `/dashboard`, `/dashboard/shared`, `/dashboard/vault`, and `/dashboard/trash`

The dashboard and account forms are currently UI scaffolding; authentication and file storage are not connected to a backend yet.
